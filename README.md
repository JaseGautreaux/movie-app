# Movie Search App

A full stack application built using python and Flask, It seaches for movies using the TMDB API and shows results with the movies poster, rating and a break overview explaining the movie.

## Features
- Search any movie by name
- Dispalys movie poster, release date, rating, and overview

## Tech Stack
- Python 3
- Flask
- HTML and CSS
- TMDB API

## How to run
1. Clone this repo
2. Install dependencies: 'pip install flask request'
3. Sign up at themoviedb.org and get a free API key
4. Replace YOUR_TMDB_KEY IN app.py with you key
5. Run: 'python app.py'
6. open browser at http://127.0.0.1:5000
